# Dex++ MCP tool catalogue

166 tools. Generated by `npm run docs` - do not edit by hand.

Every tool also accepts an optional `client` argument to target a specific connected game client.

## Session, events and utilities (20)

### `list_clients`

List Roblox clients connected to the bridge (user, place, executor, transport). Most tools act on the selected/most recent client; pass `client` to target another.

### `select_client`

Choose which connected client later tool calls default to (by id like c2, username or place id).

| parameter | type | description |
|---|---|---|
| `client` **(required)** | string |  |

### `wait_for_client`

Wait until a Roblox client connects to the bridge (e.g. right after launching the executor script).

| parameter | type | description |
|---|---|---|
| `timeout_s` | number | Default 60. |

### `server_info`

Bridge/server details: listening address, protocol, clients, call statistics, tool count.

### `get_status`

Status of the connected game client: place/job/user, executor, Dex++ version, thread identity, missing executor capabilities, bridge counters. Also reports round-trip latency.

### `get_capabilities`
